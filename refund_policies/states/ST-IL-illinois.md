# Illinois Addendum (ship-to state: IL)

## Return label fee
For orders shipped to Illinois, the $7.95 return label fee is waived on all customer-initiated returns.

## What is not changed
Restocking fees and the furniture pickup fee still apply. Return windows are unchanged.

## Everything else
All other terms follow the standard policy.
