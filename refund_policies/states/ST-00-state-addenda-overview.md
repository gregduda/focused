# State Addenda Overview

J&P publishes addenda that change specific return terms for orders shipped to certain states. These are J&P's own terms for those orders.

## Which state applies
The state is the **ship-to state** on the order (`ship_to_state`). It is not the billing state, and it is not where the customer is now. For gift orders, use the state the gift was shipped to.

## States with addenda
| State | Document | Summary |
|---|---|---|
| California | ST-CA | Electronics restocking fee 10%; small store-credit balances cash out |
| New York | ST-NY | Final sale only enforceable if shown on the order confirmation |
| Washington | ST-WA | 45-day window for apparel and footwear, outdoor gear, home goods |
| Illinois | ST-IL | Return label fee waived |
| Massachusetts | ST-MA | Furniture pickup fee $50 and restocking fee 15% |
| Florida | ST-FL | 37-day window for deliveries June 1 to November 30 |
| Texas | ST-TX | No changes |

## All other states
States without an addendum follow the standard policy with no changes.

## Scope of an addendum
An addendum changes only the items it names. Everything else in the policy still applies. Windows never stack, so a state window only helps when it is the latest deadline (POL-07).
