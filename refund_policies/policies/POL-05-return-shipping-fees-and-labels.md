# Return Shipping Fees and Labels

## The prepaid label fee
Returns use a J&P prepaid label. A **$7.95 label fee** is deducted from the refund for customer-initiated returns. Customer-initiated reasons are CHANGED_MIND, WRONG_SIZE_FIT, ORDERED_BY_MISTAKE, FOUND_CHEAPER, GIFT_UNWANTED, and LATE_DELIVERY (see OPS-05).

## When the label fee is waived
- The return reason is one of our-error reasons: DEFECTIVE, DAMAGED_IN_TRANSIT, WRONG_ITEM_SENT, or NOT_AS_DESCRIBED.
- The customer is a Summit or Peak Trailhead Rewards member (LOY-01).
- The order ships to Illinois (ST-IL).
- The return is an exchange (POL-13).
- Any one of these is enough. Waivers do not need to be combined.

## Furniture and oversized items
These items are not shipped with a label. They use freight pickup, and a pickup fee applies instead of the label fee (CAT-04). The two fees are never charged together.

## One fee per shipment
The label fee is charged once per return shipment, no matter how many items are in it. If the customer returns items from the same order in separate shipments, each shipment is charged.
